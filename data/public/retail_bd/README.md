# Bangladeshi retailer daily sales, 2013-2017 (public, real)

`dataset.xlsx`: "Supply Chain Demand Forecasting Dataset of Bangladeshi Retailer", Mendeley Data,
DOI 10.17632/xwmbk7n3c8.1, licence CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
Downloaded 20 Oct 2026, unchanged. 1,826 days (1 Jan 2013 to 31 Dec 2017) of units sold per day
for one product of one Bangladeshi retailer. Columns: row number, `date`, `sales`.

Used by `ml/notebooks/01_forecast_backtest.py` with `HISHAB_DAILY_PATH` set (WP-20 substitute
for field data, item 1). It is public data, not one of our shops, and not synthetic.
