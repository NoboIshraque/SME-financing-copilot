# Presentation deck (deliverable 02): source copy

The deck is a Slides artifact on claude.ai (exported to PDF and PPTX for the submission). This
folder is a backup of its source: `deck.json` (title, slide order, sections, typefaces) and one
`slides/<id>.html` per slide, with the speaker notes in each slide's `<aside>`. Every figure on the
slides comes from the technical documentation or the evidence bundle.
