A copilot that checks itself, and says “I don’t know”

1 Guard

Screened for prompt injection in four languages

2 Plan

A model proposes steps; code drops anything unknown

3 Check

Every number recomputed independently; mismatches removed

4 Challenge

Another model family argues against; others vote

5 Answer or abstain

Withheld when checks fail, naming what is missing

“How big a loan can I safely take?” 14 of 14 numbers recomputed and verified, 3 action cards, and a warning that the lender may ask for facts DecisionGuard does not hold.

Run offline with no model, so no model agreement is claimed. Each question has a budget of tool and model calls; agent tools can never execute an action.

The copilot is where most AI products cut corners, so we built five steps around the model. First, every question is screened for prompt injection in four languages. Second, a model proposes a plan, and code removes anything it does not recognise. Third, every number the answer states is recomputed by an independent path: the engine again, a fresh simulation, or a symbolic check of the formula. Fourth, a model from a different family argues the case against, and other models vote on the judgement. Fifth, if checks fail or votes disagree, DecisionGuard says “I don’t know” and names what is missing. In our example, all fourteen numbers checked out.
