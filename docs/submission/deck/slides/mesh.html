Here is something no single-shop tool can do. These three synthetic shops owe each other in a circle: garment owes fabric 4.5 lakh, fabric owes hardware 3.8 lakh, hardware owes garment 3.2 lakh. That is 11.5 lakh taka of debt, and each shop is waiting for the next to pay. Minimum-cost netting clears all of it with 1.9 lakh taka of cash, moving only along debts that already exist. Every owner must approve with a one-time code, and one refusal cancels the round. The settled record is sealed with a salted hash that can be anchored on Ethereum Sepolia, so anyone can later check it was not edited, without the chain ever seeing a name or an amount.
