## Milestones
1. **Price ingest:** TCB Dhaka daily prices, AgriPriceBD dataset, World Bank Pink Sheet (monthly)
   → PricePoint with source and date. Scheduled fetch; cached snapshots committed as fixtures for tests.
2. **Watchlist & alerts:** each SME's tracked inputs (from its purchase history); alert on moves
   past threshold vs 4-week median; honest timestamp of the data ("published today").
3. **Vendor ranking:** landed cost = price + delivery cost + expected delay cost + reliability
   penalty from the SME's own history; recommend vendor and route (pickup vs delivery) with breakdown.
4. **Negotiation engine (N19):** for a buyer deal compute walk-away point, target terms, and
   trade-offs (price vs payment term vs advance vs volume) using the SME's cost of money (best
   financing APR from WP-06 interface); output a step-by-step script with the numbers behind each step.
5. **API:** `GET /market/prices`, `GET /market/alerts`, `POST /market/vendors/rank`, `POST /market/negotiate`.

## Tests (≥ 50)
Parsers on saved fixtures; alert threshold table; landed-cost hand cases; ranking stable under
irrelevant noise; negotiation never recommends terms below walk-away (property).
