1. `01_forecast_backtest.ipynb` — real transactional data (UCI Online Retail II) aggregated to

3. `03_injection_classifier.ipynb` — fine-tune a small multilingual encoder (mDeBERTa-v3-base or
   XLM-R base) on public prompt-injection data + generated EN/BN/Banglish/ZH paraphrases; report
   precision/recall per language; export ONNX < 300 MB (Drive) + quantised < 100 MB (repo/Release).
4. `04_market_backtest.ipynb` — AgriPriceBD daily prices: how early price-move alerts fire vs
   actual moves.
