## Milestones
1. `infra/docker-compose.yml` (site address from `DEPLOY_DOMAIN` = `hishab.quadbits.net`;
   Caddy obtains the Let's Encrypt certificate automatically): api, worker (schedulers: market fetch, alerts, anchor, audit drill),
   postgres, caddy (TLS, CSP, compression, serves `web/dist`). Healthchecks.
2. `deploy.yml`: on merge to `main` → build → SSH to the Singapore server → `docker compose up -d`
   → smoke test → roll back on failure.
3. Backups on the server: hourly `pg_dump` (keep 48), copied off-server.
4. China readiness (no team member is in China, so it is proven by tools and by design):
   - **External-domain audit (automated):** a Playwright test loads every screen and records
     every host the page contacts; it fails if any host is not our own domain. This guarantees
     nothing depends on Google, YouTube, Vercel, Facebook or other blocked services.
   - Self-hosted fonts and assets, gzip/brotli, small bundles, no third-party analytics.
   - **China-node checks (manual, 10 min, RUNBOOK §5.6):** 17CE, BOCE and ITDog test HTTP
     access from many mainland cities; GreatFire Analyzer checks whether the domain is blocked.
     Screenshots + numbers go to `docs/submission/evidence/china.md`.
5. Frontend mirror on Vercel (for non-China judges) pointing at the same API.
6. `docs/DEPLOY.md`: one-page "deploy from zero" for judges (deliverable 04).
