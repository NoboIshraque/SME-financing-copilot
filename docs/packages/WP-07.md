# WP-07 — Analysis, variance, scenarios, stability score

Owner: A1 (PC-1) · Branch: `wp-07-analysis` · Wave 2 · Test quota: 90 · Features: **N1, N12, N16**, supports N4
Owns: `backend/app/engines/analysis/`, `backend/app/api/analysis.py`, `backend/tests/analysis/`
Depends on: WP-01, WP-04, WP-06 interface.

## Milestones
1. **Statements:** cash-basis monthly P&L, balance-sheet-lite (cash, receivables, stock if
   known, payables, loans), cash-flow statement.
2. **Ratios** with formulas and provenance: gross margin, net margin, current, quick, DSCR,
   interest cover, DSO, DPO, DIO, cash conversion cycle, burn, runway, concentration (top customer share).
3. **Expected vs reality (N1):** freeze forecast snapshots weekly/quarterly; compare to actuals
   line by line; rank variances; forecast accuracy score; feed a correction factor back to WP-04.
4. **Scenarios (N12):** Monte Carlo over sales, delays, input prices, rates, shocks; compare
   candidate decisions by expected outcome, worst-5% outcome, P(buffer breach); recommend the best
   risk-adjusted path.
5. **Decision stability score (N16):** for any Recommendation run ~10 variations — economic
   stress (late payer, −10/−20% sales, +8% inputs, +2pp rates, surprise bill) and irrelevant
   noise (row order, renamed parties, reworded request). Score = share of variations where the
   choice holds; noise flips flagged "unreliable"; return "what would flip this".
6. **API:** `GET /analysis/statements`, `/ratios`, `/variance`, `POST /analysis/scenarios`, `POST /analysis/stability`.

## Tests (≥ 90)
Every ratio vs hand cases (parametrised); balance identity holds (property); variance sign and
ranking table; snapshot immutability; scenario determinism by seed; stability: a noise-only
variation never changes a deterministic engine's choice (property) and stress flips are reported.
