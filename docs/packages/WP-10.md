# WP-10 — LLM gateway + agents

Owner: B2 (PC-2, second terminal) · Branch: `wp-10-agents` · Wave 2 · Test quota: 90 · Features: **N7, N8, N9, N10, N11, N17, P13**
Owns: `backend/app/llm/`, `backend/app/agents/`, `backend/app/api/copilot.py`, `backend/tests/agents/`, `backend/tests/fixtures/llm/`
Depends on: WP-03 gate, WP-11 tiers, engine interfaces from WP-04–09.

## Goal
An agent that completes real tasks by calling engines, never inventing numbers, checked by a
symbolic checker and a critic from another model family, abstaining when unsure.

## Milestones
1. **Gateway** (`llm/gateway.py`): OpenAI-compatible client per provider — Gemini (brain),
   Groq `gpt-oss-120b` + Groq Qwen (voters/critic; fallback `gpt-oss-20b`, then Gemma), Ollama
   (private mode), deterministic planner (always available). Calls `privacy.assert_safe` on every
   payload (fail closed). Per-provider usage counters + graceful degradation; response cache by
   hash of the anonymised prompt; recorded fixtures for tests; `npm run live-llm-check` saves real traces.
2. **Tools:** typed tool registry wrapping engine APIs (forecast, gaps, receivables plan,
   financing match, ratios, scenarios, stability, mesh propose, market, negotiate, draft message).
   Every tool result carries provenance.
3. **Orchestrator + sub-agents (N8):** plan → dispatch sub-agents in parallel → collect →
   compose a Recommendation with ActionCards (P9). Tool budget per run (P13).
4. **Claims + checker (N8):** the composer emits `Claim{text, value, formula_id, inputs}` for
   every number/assertion; the checker recomputes from facts (exact recomputation, SymPy for
   formula identities) and rejects mismatches; rejected claims are removed and logged.
5. **Critic (N11):** a different model family argues the case against; strongest objection
   attached to the Recommendation.
6. **Agreement (N9):** for judgements (intent, option choice, extraction) above a stakes
   threshold, ≥ 2 other models vote; agreement rate is the confidence.
7. **Self-loops (N10):** stress via WP-07 stability; stakes-tiered; cached.
8. **Abstention (N17):** abstain if agreement < threshold(stakes), data insufficient (per-tool
   minimum history), or checker can't verify; message names exactly what's missing; log every abstention.
9. **API:** `POST /copilot/ask` (chat + returns Recommendation), `GET /copilot/abstentions`.

## Tests (≥ 90, all offline with fixtures)
Gateway refuses unsafe payloads; fallback chain order; cache hit; tool registry contract;
injected wrong number is rejected by the checker (parametrised over every metric); critic
attached; agreement math table; abstention triggers table (each reason); stakes thresholds;
tool-budget stop; no number in any final answer lacks provenance (property over fixture runs).
