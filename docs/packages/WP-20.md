## Consent text (read aloud in Bangla, sign the English copy)
"We are students from BUP building a free tool to help small shops manage cash and find fair
finance, for a university competition. With your permission we will use copies of your payment
statements and ledger pages. We will remove your name, phone numbers, your customers' names and
anything that identifies you before using them. Nothing will be published that identifies you.
You can withdraw at any time by calling [Labib's number]."
Name / shop / date / signature.

## Interview (5 minutes)
1. When in the month or year is cash tightest? Why?
2. How much is owed to you right now, roughly, and by how many customers?
3. Have you borrowed for the business? From whom, at what cost, and what was hard?
4. How do you remind customers to pay? What happens when you do?
5. Would you trust an app that drafts reminders and compares loans for you? What would make you trust it?

## Collect
- Merchant statement export (bKash/Nagad), 3–6 months, if they agree.
- Photos of 2–4 baki-khata pages.
- Typical input prices and 2–3 suppliers.
- One quote we may use, anonymised ("— grocery owner, Mirpur").

## Anonymise (after each shop; PC-4, PowerShell)
Raw files stay in the private Drive folder, one folder per shop (the tool refuses a folder inside the repo).
1. Baki-khata photos: type the pages into a sheet first (`customer, phone, date given, amount, paid date,
   amount paid, note`) and save it as CSV or XLSX in the shop's raw folder. Photos never go in the repo.
2. Optional but recommended: `known_names.txt` in the raw folder with the owner's, shop's and staff names,
   one per line (masked wherever they appear in free text).
3. Run (neutral shop id, no real names):
   ```powershell
   cd C:\hishab\repo
   git switch main; git pull; git switch -c wp-20-data   # first shop only; later: git switch wp-20-data
   uv --directory backend run python -m app.privacy.shopfiles "G:\My Drive\hishab-raw\shop01" --shop shop01-grocery
   ```
4. The console lists any words left in free-text columns. If one is a person's or shop's name, add it to
   `known_names.txt` and run step 3 again (tokens stay the same between runs).
5. Open `data\real_anonymised\shop01-grocery\REPORT.json` and the CSVs: no names, numbers or IDs. A file
   with anything left is **refused** (not written) and listed under `refused` in the report.
6. `git add data\real_anonymised; git commit -m "WP-20: shop01 anonymised"; git push -u origin wp-20-data`,
   then comment "done: shop01 anonymised" on the Mission control issue.
The vault (encrypted originals) and its key are in `C:\Users\<you>\.hishab\`: never copy that folder
anywhere; delete it with the raw files after the competition.
