# WP-00 — Foundation, contracts, CI, seed data

Owner: Orchestrator · Branch: `wp-00-foundation` · Wave 0 · Test quota: 40
Owns: everything not owned by another WP at creation time; afterwards only
`backend/app/contracts/`, `data/synthetic/`, root `package.json` scripts, root config.

## Goal
Everything the parallel sessions need on day one: a runnable skeleton, frozen shared schemas,
seeded synthetic data, CI, and backup tooling.

## Milestones
1. **Scaffold.** `backend/` (uv, FastAPI app factory, settings from env, SQLAlchemy 2 + SQLite
   for dev/tests, Postgres via `DATABASE_URL`), `web/` (Vite React TS + Tailwind + Vitest +
   i18n en/bn/zh), root `package.json` scripts from CLAUDE.md (cross-platform: Windows has no make), `backend/.env.example`, `.gitignore`
   (`.env`, `*.db`, `ml/artifacts/*.ckpt`, `data/raw/`).
2. **Contracts** in `backend/app/contracts/` (Pydantic v2, all `Decimal` money):
   `common` (Money, DataMode, Period, Currency, Tier), `party` (Party, PartyRole),
   `ledger` (Transaction, Channel, Direction, Invoice, Bill, RecurringObligation),
   `facts` (Fact, Provenance, FormulaRef), `market` (PricePoint, VendorQuote),
   `cash` (ForecastPoint, ForecastBand, CashGap, Alert, AlertTier, SmoothingLever),
   `financing` (FinancingProduct, Eligibility, FinancingOption, LenderProfile),
   `analysis` (Ratio, Variance, Scenario, StabilityReport),
   `mesh` (Obligation, NettingRound, Settlement, Attestation, AnchorReceipt),
   `agents` (Claim, CheckResult, Vote, AgreementReport, Abstention, Recommendation, ActionCard),
   `security` (Role, Principal, Approval, AuditEvent), `messaging` (MessageDraft, Channel).
   Export JSON Schema + `docs/api/contracts.json`; a test fails if they drift.
3. **Synthetic SME universe** `data/synthetic/generate.py` (seeded, deterministic): 5 Dhaka SMEs
   (grocery, pharmacy, fabric wholesaler, garment subcontractor, hardware), 18 months of daily
   transactions with day-of-week, month-end and Eid/Boishakh seasonality, ~60% bKash/Nagad,
   baki (credit sales) with per-customer delay habits, recurring rent/salary/EMI, 2 disputes,
   and a **circular debt ring** between three of the SMEs for the mesh demo. Every row
   `data_mode="synthetic"`. Output CSV in each source's real export format (bKash-style,
   bank-style, ledger-style) so WP-02 parses realistic files.
4. **CI** `.github/workflows/ci.yml`: ruff, pytest, eslint, tsc, vitest, gitleaks secret scan,
   pip-audit, npm audit (high only). Prints test counts per layer.
5. **Tooling:** `scripts/autosave.ps1`, `scripts/autosave.sh`, `.claude/settings.json`,
   `AGENTS.md` (copy of CLAUDE.md for non-Claude agents), `npm run evidence` stub.

## Tests (≥ 40)
Contract round-trips, JSON-schema drift check, generator determinism (same seed → same hash),
seasonality present (Eid weeks > baseline), ring exists, every row labelled synthetic, settings load.
