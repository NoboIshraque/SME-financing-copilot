## Goal
Tackle each cause of unpaid receivables listed in FEATURES.md Q2.

## Milestones
1. **Aging** (0–30, 31–60, 61–90, 90+), DSO, per-customer payment history.
2. **Risk score 0–100** per open invoice (delay model from WP-17 if present; else empirical:
   history, amount vs usual, dispute flag, recency). Explainable: top 3 factors.
3. **Credit limit suggestion** per customer from history; "stop credit" flag for chronic late payers.
4. **Reminder ladder** (pre-due −3 days, due day, +3, +10, +20) → MessageDraft requests to WP-12;
   payment link/QR placeholder per reminder.
5. **Dispute log:** open/resolve; disputed invoices leave the "likely" forecast until resolved.
6. **Early-pay discount calculator:** annualised cost of "x% off if paid in d days" vs best
   financing APR (WP-06 interface) → offer only when cheaper.
7. **API:** `GET /receivables`, `POST /receivables/{id}/dispute`, `GET /receivables/plan`.

## Tests (≥ 60)
Aging boundary table; DSO hand cases; risk monotonicity properties (more lateness → never lower
risk); limit never exceeds policy cap; ladder dates table; dispute exclusion; discount
annualisation table vs hand-computed values.
