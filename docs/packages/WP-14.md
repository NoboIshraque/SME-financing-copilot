# WP-14 — Frontend

Owner: B1 (PC-2) · Branch: `wp-14-web` · Wave 1–3 · Test quota: 110 (Vitest) · Features: **N13 (UI), P6, P9, P12**, all screens
Owns: `web/src/` (not `web/e2e/`)
Depends on: WP-00 contracts (generate TS types from `docs/api/contracts.json`); mock API until each backend router lands.

## Design
Mobile-first (360 px), calm and trustworthy; big numbers, one primary action per screen.
Self-hosted fonts that cover Bangla and Chinese (e.g. Noto Sans Bengali / Noto Sans SC subsets).
No external CDNs. Light/dark. i18n en/bn/zh with a language switch on every screen.

## Milestones
1. **Shell:** routing, auth screens (WP-11), language switch, API client with typed contracts,
   mock server for offline dev, demo-mode banner ("synthetic data").
2. **Today:** alerts by tier, cash runway, top 3 action cards (P9) with one-tap approve.
3. **Cash:** 13-week chart with P10/P50/P90 bands, gap markers, what-if sliders.
4. **Receivables:** aging, risk, reminders, disputes.
5. **Financing:** match form → ranked options with true cost, eligibility reasons, fit, lender
   check; "draft application" card.
6. **Analysis:** statements, ratios, expected-vs-reality, scenarios, stability bar + "what would flip this".
7. **Mesh:** obligation graph, proposed netting round, approve flow, testnet tx link.
8. **Market:** watchlist, price alerts, vendor ranking, negotiation script.
9. **Messages & approvals inbox**, **Reports & Passport**, **Trust & audit** (audit verify,
   abstention log, audit-drill score), **Settings**.
10. **Provenance drawer (N13):** every number is a button → formula, inputs, source rows.
11. **Copilot panel:** chat that returns Recommendations as cards (critic objection, agreement,
    stability, abstention messages shown clearly). Upload flow for statements/photos (WP-02).
12. **PWA + accessibility:** installable, offline shell, WCAG 2.1 AA (axe clean).

## Tests (≥ 110 Vitest)

## Notes
- **API modes** (`web/src/api/apiMode.ts`): `live` (real backend only; production default),
  `mock` (offline mock in `web/src/mocks`, always labelled in the banner), `auto` (development
  default: the real backend first, the mock only for routes whose router has not landed:
  FastAPI's bare `{"detail":"Not Found"}`, 405, or the API not running). Production builds
  follow `VITE_API_MODE` at build time; the mock code is a separate chunk that live builds never load.
- **Shapes the web expects** are typed in `web/src/api/types.ts` (envelopes) and
  `web/src/api/endpoints.ts` (routes); the mock serves exactly these. For WP-11:
  `POST /api/auth/login {email,password}` → `{status:"ok",session}` or `{status:"totp_required"}`;
  `POST /api/auth/login/totp {code}` → `Session`; `GET /api/auth/me` → `Session` (401 signed out);
  `POST /api/auth/logout` → 204; `GET /api/auth/demo-accounts` → `DemoAccount[]` (demo mode only,
  optional `totp_hint` = current demo code). `Session = {principal, display_name, business_name,
  totp_enrolled, data_mode}`. Errors: 401 `error.invalid_credentials`, 401 `error.invalid_code`,
  423 `error.account_locked` with `detail.retry_after_minutes`. WP-11 implements these shapes;
  the client signs the user out only on 401 `not_authenticated` (a wrong TOTP or step-up code is
  401 `error.invalid_totp` / `error.invalid_step_up` and stays on screen). EXECUTE calls send
  `X-Step-Up-Code` and `X-Idempotency-Key` headers.
- **Routes the other screens call** (all envelopes in `web/src/api/types.ts`):
  WP-04 `GET /api/cash/forecast` → `CashForecast {band, figures}` (figure label_keys
  `cash.closing_balance`, `cash.buffer_target`, `cash.runway_days`, `cash.lowest_likely_balance`),
  `GET /api/cash/alerts` → `Alert[]`, `GET /api/cash/gaps` → `CashGap[]`, `POST /api/cash/whatif`
  `WhatIfRequest` → `CashForecast`. WP-05 `GET /api/receivables` → `ReceivablesOverview`,
  `GET /api/receivables/plan` → `{reminders: ActionCard[]}`, `POST /api/receivables/{id}/dispute
  {reason}` and `/resolve` → `ReceivableRow`. WP-06 `POST /api/financing/match FinancingNeed` →
  `FinancingMatch {need, options, lenders, application}`. WP-07 `GET /api/analysis/statements|ratios|variance`,
  `POST /api/analysis/scenarios {decisions}`, `POST /api/analysis/stability {recommendation_id}`.
  WP-08 `GET /api/mesh/obligations` → `MeshGraph {obligations, labels}`, `GET /api/mesh/rounds` →
  `NettingRound[]`, `POST /api/mesh/rounds/{id}/approve` (step-up), `GET /api/mesh/rounds/{id}/verify`.
  WP-09 `GET /api/market/prices|alerts`, `POST /api/market/vendors/rank {commodity, quantity}`,
  `POST /api/market/negotiate`. WP-10 `GET /api/copilot/today` → `Recommendation` (Today falls back
  to the alerts' fixes while it is missing), `POST /api/copilot/ask {question}` (injection: 422
  `error.input_quarantined`), `GET /api/copilot/abstentions`. WP-11 (live) EXECUTE cards: `POST /api/approvals {card}` →
  `/{id}/approve` (owner, step-up) → `/{id}/execute`; accountants only request; `GET
  /api/approvals?status=pending` feeds the inbox; `GET /api/audit/verify|events|anchors`. DRAFT
  cards approve the message draft in `payload.draft_id` via WP-12 (none yet: "Review in Messages"). WP-12
  `GET /api/messages/drafts`, `POST /api/messages/{id}/approve|send`, `GET|POST /api/settings`.
  WP-13 `GET|POST /api/reports/passport`, `GET /api/reports/shares`, `POST
  /api/reports/passport/{id}/share` (step-up), `POST /api/reports/shares/{id}/revoke`, public
  `GET /api/verify/{passport_id}` (page: `/verify/:passportId`). WP-16 `GET /api/trust/drill`.
  WP-02 (live) `POST /api/ingest/preview` (multipart `file` + `tenant_id`), `POST /api/ingest/commit
  {tenant_id, preview_id, file_digest, confirm}` (only unflagged OCR drafts start ticked). WP-01
  `GET /api/explain/{figure_id}` (live; the drawer falls back to the figure's own provenance on 404).
- Every number renders through `FigureValue`/`Num` (`web/src/components/FigureValue.tsx`) and opens
  the provenance drawer. Server `*_key` strings are translated; unknown keys read as words.
- Nav visibility per role is a UI convenience (`web/src/navigation.ts`); the API enforces access.

  dependency), `web/index.html` (apple-touch-icon), `web/public/pwa-*.png` from
  `web/scripts/gen-icons.mjs`. Added dependency: `@fontsource/noto-sans-sc` (one weight, behind
  system CJK fonts, never precached).
