# WP-14 — Frontend

Owner: B1 (PC-2) · Branch: `wp-14-web` · Wave 1–3 · Test quota: 110 (Vitest) · Features: **N13 (UI), P6, P9, P12**, all screens
Owns: `web/src/` (not `web/e2e/`)
Depends on: WP-00 contracts (generate TS types from `docs/api/contracts.json`); mock API until each backend router lands.

## Design
Mobile-first (360 px), calm and trustworthy; big numbers, one primary action per screen.
Self-hosted fonts that cover Bangla and Chinese (e.g. Noto Sans Bengali / Noto Sans SC subsets).
No external CDNs. Light/dark. i18n en/bn/zh with a language switch on every screen.

## Milestones
1. **Shell:** routing, auth screens (WP-11), language switch, API client with typed contracts,
   mock server for offline dev, demo-mode banner ("synthetic data").
2. **Today:** alerts by tier, cash runway, top 3 action cards (P9) with one-tap approve.
3. **Cash:** 13-week chart with P10/P50/P90 bands, gap markers, what-if sliders.
4. **Receivables:** aging, risk, reminders, disputes.
5. **Financing:** match form → ranked options with true cost, eligibility reasons, fit, lender
   check; "draft application" card.
6. **Analysis:** statements, ratios, expected-vs-reality, scenarios, stability bar + "what would flip this".
7. **Mesh:** obligation graph, proposed netting round, approve flow, testnet tx link.
8. **Market:** watchlist, price alerts, vendor ranking, negotiation script.
9. **Messages & approvals inbox**, **Reports & Passport**, **Trust & audit** (audit verify,
   abstention log, audit-drill score), **Settings**.
10. **Provenance drawer (N13):** every number is a button → formula, inputs, source rows.
11. **Copilot panel:** chat that returns Recommendations as cards (critic objection, agreement,
    stability, abstention messages shown clearly). Upload flow for statements/photos (WP-02).
12. **PWA + accessibility:** installable, offline shell, WCAG 2.1 AA (axe clean).

## Tests (≥ 110 Vitest)
Component tests per screen (renders with fixtures, empty and error states), i18n completeness
(every key in en/bn/zh), provenance drawer opens for every number component, action-card tier
labels, currency/number formatting in BN and ZH, axe checks on key screens.
